# 雪球元素外觀與戰鬥動畫 — 0.3.1

原生版先前的元素切換只改變光圈，普攻則切換到尚未套用雪球毛色的 `snowball-combat` 圖集，造成攻擊前後像不同角色。這次讓吃果實、切換形態及戰鬥共用同一套角色外觀，並替發射的氣功建立各元素獨立的形狀、運動與命中效果。

## 角色素材

所有原生動作都使用已確認的 `player/snowball.png` 44 格圖集；臉、毛色、身形與腳底定位保持一致。普攻使用同圖集的伸爪、前撲及收招姿勢，衝刺、施法、受傷和倒地也不再切換到舊戰鬥素材。

`SnowballAppearance` 使用逐格檢查的 44 格定位表，將柔和領巾與小吊飾放在下巴下方，耳飾貼近耳尖；側面領口會收窄，披肩高度隨姿勢調整。蜷縮／翻倒時隱藏被身體遮住的配件，避免浮空；勝利皇冠旁不再疊加耳飾。切回原生形態時全部隱藏。PNG 原始檔沒有被重新繪製或染色。

| 形態 | 雪球外觀 | 氣功飛行與命中 |
| --- | --- | --- |
| 原生 | 原本的雪球 | 星光尖鋒與分叉尾流，散出星芒 |
| 火焰 | 火焰披肩、耳焰、尾焰 | 紅橙外焰、金色內焰、白熱核心、飄散火星 |
| 旋風 | 綠色雙層飄帶、羽葉耳飾與尾飾 | 三道彎曲風刃、扭動尾流、羽葉碎片 |
| 水波 | 水色披肩、滴狀耳飾、魚尾狀尾飾 | 捲浪輪廓、白色浪花、藍色高光與水滴 |
| 雷電 | 紫色披肩、金色電光耳飾與尾飾 | 每秒 12 次形變的分岔電弧、金色外層與白色電芯 |
| 大地 | 岩晶肩甲、晶體耳飾與尾飾 | 三塊有明暗面的旋轉岩晶、碎石與晶屑 |

吃果實與切換形態有短暫元素爆發；普攻有爪擊弧線和對應碎片。氣功分成發射、飛行、命中三段；蓄力比例決定尺寸，滿蓄力增加前緣亮芒，既有星貓爆發保留各屬性形狀。

## 運行與維護

- `ios/App/App/NativeGame/ElementalVisuals.swift` 定義形狀、色盤、氣功與短暫爆發；使用 SpriteKit path 與既有圖集，不依賴網路或新增素材下載。
- `ios/App/App/NativeGame/SnowballAppearance.swift` 負責持續保留的元素配件；果實種類改變才重建配件節點，動作變化只更新位置與材質。
- 新效果由遊戲模擬時間更新；暫停不繼續推進。氣功向左發射時，頭部、尾流和分岔一起鏡射。
- 新氣功的碰撞半徑、傷害、能量消耗、速度、穿甲與元素規則沿用原值；尾流只是視覺效果，不增加命中範圍。
- 每發氣功保留固定數量的碎片，最多保留 20 個短暫爆發。減少動態效果會降低碎片數、停止外觀擺動與電弧閃動，保留辨識元素的形狀。
- 這次修改僅在原生 iOS 分支；網頁與 Android 仍使用原有 Phaser 版本。

## 驗證方式

新增測試會真正以 SpriteKit 渲染角色，確認五種果實吃下後有畫面變化、六種形態的像素各不相同、切回原生形態會移除配件，以及每個攻擊／衝刺／施法／受傷影格都來自相同雪球圖集。另檢查向左發射、暫停和效果移除；原本的碰撞、傷害與穿甲測試繼續執行。

模擬器會保存 12 張元素動畫影格，包含原生與五種元素的待機、攻擊、短按、滿蓄力及命中效果，以及 44 個姿勢的配件對齊圖，供實際視覺檢查。另比較各形態的眼睛與嘴部像素，避免配件再次遮臉。UI 測試會從風果實旁走過去，實際吃下果實、普攻、蓄力及切回原生形態。測試用起點僅存在 Debug 的隔離存檔中。

完成的 CI、視覺檢查及 TestFlight 發行結果記錄在 [VERIFICATION.md](VERIFICATION.md)。實體 iPhone 的效能與操作手感仍需裝置測試。
