# 第一關戰鬥試玩版

依據 `GAME_DESIGN.md`，本輪完成 Home 的第一個可玩戰鬥版本，未發布到 GitHub Pages。

## 已實作

- 三段肉球攻擊、空中攻擊、衝刺免傷、受傷保護、小怪擊退與非致死解除狀態。
- 火焰果實台、火焰爪、火球、呼嚕能量，以及鍵盤 Q／點擊果實卡切換。
- 掃地無人機和發條老鼠，共四處一般遭遇；扳手會額外召喚最多兩隻無人機。
- 開放陽台通道；鑰匙、星星、老鼠和玩具箱都不阻擋魔王戰。
- 加大的陽台場地與三階段扳手：衝撞／吸力、螺絲炸彈／無人機、過熱散熱口。
- 魔王入口重試、和解對話、徽章／同伴結算、永久火焰及攻擊力 +10%。
- 繁體中文主選單、生命／能量／元素 HUD、魔王血條、手機四個主要動作键。
- 高解析素材經規整後匯入；外部原素材包未變更。

## 存檔

保留現行 v1 儲存鍵與設定、探索進度、最佳成績。新增獨立 `adventure` 欄位記錄火焰、扳手與固定 10% 加成；舊版的探索通關不會自動取得新版魔王獎勵。

`fire-trial` 只保留於當次出勤，包含死亡／魔王重試與重新開啟。打贏扳手後才永久解鎖；重玩仍保留能力，重複通關不會重複疊加攻擊力。完整七關存檔 v2 遷移留待框架階段。

## 驗證

- TypeScript 型別檢查通過。
- 自動測試涵蓋連段時序、地面／空中範圍、三階段魔王、預警／反擊窗口、同步死亡重試、暫停計時、主線無收集門檻、獎勵保存與舊存檔相容。
- 實際瀏覽器整合 fixture 通過：鍵盤移動、跳躍、攻擊圖格切換、火球耗能、元素切換、衝刺、小怪解除、無鑰匙及零星星進魔王、受傷保護、暫停、死亡重試、和解通關與重玩保存。未出現 runtime error。
- 整合 fixture 使用定位來隔離個別功能，也直接扣魔王血量驗證階段與結算。因此這些結果不等同無輔助完整遊玩、難度或時間驗收。
- 桌機與 844×390 模擬觸控版面經瀏覽器畫面檢查；尚未驗證實體手機多點觸控。
- 此桌面工具環境無法建立 Node 子程序的管線（EPERM），標準 Vite 預覽／建置與 Playwright 啟動因此受阻。本次用原生 esbuild CLI 產生本機測試包，使用內建瀏覽器執行相同 fixture。標準 `npm run build` 尚待一般終端或 CI 驗證，未宣稱通過。

一般環境使用 `npm ci`、`npm run dev`、`npm test`、`npm run build`。開著開發伺服器時可執行 `npm run test:browser`，測試結果輸出至 `test-results/`。

## 尚待完善

目前角色戰鬥是整理過的關鍵姿勢動畫，尚未完成所有逐格過渡、各姿勢的任務項圈／鈴鐺，以及全部火元素覆蓋。此輪保留原移動圖集；詳見 `ADVENTURE_ASSETS.md`。

魔王時間 90–150 秒與第一關 8–10 分鐘是設計目標，尚未經首次玩家計時驗證。完美閃避／反擊、下墜踩擊、後續四元素、其餘六關和飛船基地不在本輪實作範圍。
