# 七關冒險實作說明

目前程式提供七次出勤的開場、探索路線、一般遭遇、三階段魔王、和解、獎勵、下一關、重玩與最終自由巡邏。這份文件描述實際可玩的版本；[GAME_DESIGN.md](GAME_DESIGN.md) 是更完整的製作目標，[PHASE1.md](PHASE1.md) 是已被本輪取代的歷史紀錄。

## 關卡與流程

| ID | 關卡／魔王 | 當前場景與戰鬥重點 |
|---|---|---|
| `home` | 沙發底下的警報／扳手 | 公寓、廚房、陽台；衝撞與吸力、炸彈與無人機、過熱反擊 |
| `rooftop` | 天台風暴／風翎 | 屋頂、水塔、曬衣繩、上升氣流；俯衝、羽毛飛彈、旋風 |
| `basement` | 地下水世界／波波 | 管線與積水機房、水中浮力；水柱、泡泡、機甲滾動 |
| `parking` | 停電停車場／伏特 | 停車場、充電樁、預警電纜；高速突進與落雷區 |
| `foundations` | 地基大震動／土豆 | 根脈礦坑、水晶、裂紋牆捷徑；地面震波與落石 |
| `floor13` | 十三樓泡泡龍之家／泡泡龍媽媽 | 遊戲房、可乘坐的浮動泡泡；泡泡、尾掃、幼龍支援 |
| `nightark` | 夜空中的回家路／夜墨 | 星橋、低重力區、永夜方舟；複製元素、重力場與落雷 |

新存檔只開放 `home`。每關魔王解除控制、進入和解後，記錄該關徽章與同伴，開放下一關；結算保存本關最佳成績。收集品、鑰匙和探索支線均為可選。前五關在前段試用新果實，試用狀態會保留於本次檢查點／魔王重試／重新載入，永久果實則隨徽章取得。

「下一次出勤」開始下一關；「再玩這一關」保留永久能力並重設本次路線。主選單的星圖能選取所有已解鎖關卡；飛船名冊依真實存檔顯示同伴、徽章和五元素收藏。名冊目前是選單介面，沒有可步行探索的飛船基地。

最終和解邀請夜墨加入巡邏隊，而非摧毀他的飛船。結局按鈕直接開啟星圖，玩家可帶著永久能力自由重玩七關；沒有每日任務排程或背景自動活動。

## 操作與容易上手的戰鬥

- 移動：A／D、方向鍵，或手機左右鍵。
- 跳躍：Space／手機跳躍；按住可跳得較高。
- 肉球：J／E／手機肉球；靠近可互動物件時切換為互動。
- 特殊攻擊：輕按 K／手機「集氣」並放開，消耗 16 能量。
- 集氣：按住 K／「集氣」最多 1,200 ms，提示蓄滿後放開；一般滿蓄力消耗 30 能量，中途釋放會依時間與現有能量調整威力。
- 切換形態：Q／點左下果實卡，循環原生形態與目前取得的果實；切換會取消未發射集氣。
- 衝刺：Shift／手機衝刺；暫停：Esc／暫停鍵。

原生形態也能發射集氣能量波。普通三段連擊不耗能，命中會補少量能量。能量隨遊玩時間回復；暫停、對話與失去焦點時停止或取消對應操作，避免鬆開按鍵後意外開火。

愛心罐頭碰到即回復 2 心與 20 能量，不需要新增補血按鍵。只有生命或能量需要補充時才會消耗。路線上有固定補給；魔王場內三個固定罐頭在取得 12 秒後可再生；生命不高於 2 心時，附近可出現額外救援罐頭，救援冷卻 18 秒。

新檢查點回滿生命。魔王戰失敗回到入口並補滿生命和能量、重設場內補給、保留本關果實試用。受傷後有保護時間；一般形態與普通攻擊仍可傷害魔王。

## 五元素與永久獎勵

| 元素 | 當前能力 | 取得關卡 |
|---|---|---|
| 火焰 | 強化肉球、燃燒命中、火球與蓄力火球 | 第一關 |
| 風 | 二段跳、按住跳躍滑翔、風色能量波；上升氣流增強 | 第二關 |
| 水 | 水波攻擊附帶 4 秒、可抵擋一次傷害的氣泡盾；水池浮力加強 | 第三關 |
| 雷電 | 命中附近小怪時連鎖電擊、衝刺距離加長；安全通過停車場電纜 | 第四關 |
| 大地 | 近身範圍震擊、每 7 秒可抵擋一擊、裂紋牆捷徑；安全通過電纜 | 第五關 |

扳手提供固定 10% 攻擊提升；波波把生命上限由 5 提升至 6；伏特把能量上限由 100 提升至 120，並加快回復；土豆強化第三段連擊。重玩取得相同徽章不會重複疊加獎勵。

第六關啟用元素連攜：在 4.5 秒內切換不同元素並接續特殊攻擊，取得 1.4 倍連攜傷害。取得第六關徽章後永久保留。泡泡龍同伴在危急時可提供一次救援，魔王重試時重設；目前連攜採共用傷害加成，設計書中各種具名元素組合的獨立狀態與場景效果仍待完善。

第七關啟用星貓爆發；持有至少 100 能量時放出滿蓄力攻擊，改為消耗 100 能量，並對魔王與附近敵人造成額外攻擊。取得夜墨徽章後可在重玩時使用。這是一般 30 能量滿蓄力的特例。

## schema v2 與相容性

JSON 內容 `version` 為 2，儲存鍵仍為 `snowball-quest-save-v1`。這是刻意保留的相容介面，瀏覽器 localStorage 與原生存檔適配器使用相同位置。

- `currentStage` 與 `run` 保存當前出勤、檢查點、收集 ID、旗標、生命和遊玩時間。
- `stages` 保存各關完成狀態、最高收集數與最短完成時間。
- `bossBadges` 是永久解鎖依據；`unlockedStages`、`unlockedFruits`、`unlockedSupport` 與生命／能量上限由已取得徽章正規化。
- `adventure` 保留第一關火焰、扳手與固定攻擊加成的相容欄位。
- v1 的有效設定與探索進度保留；已取得的扳手獎勵遷移為 `home` 徽章。僅有舊探索完成紀錄不會授予新版魔王獎勵。
- 舊 `cafe`、`garden`、`ending` 成績移到 `legacyStages`。若舊版當前目的地已不存在，回到安全的第一關起點。
- 未解鎖目的地無法從星圖啟動。重玩保留永久獎勵、設定與各關成績，只清空當次出勤。

## 美術與驗收範圍

已接入 8 種小怪、7 位魔王、5 種果實與 28 個雪球戰鬥關鍵姿勢。原移動圖集保留；後六關背景、平台裝飾、環境和多數攻擊特效使用 Phaser 圖形繪製。碰撞尺寸與圖像分開控制。

七關可玩流程不代表設計書每個細節都已完成。正式逐格過渡、完整元素專用角色動畫、逐姿勢項圈／鈴鐺、美術背景層、獨立的元素組合狀態、進一步的可選支線與完整基地互動仍有製作空間。當前各關魔王有不同招式與三段血量進程，但設計書中的所有平台破壞、全場重力翻轉、逐位同伴演出等仍未全部逐項還原。

自動規則測試和瀏覽器功能驗證可確認載入、操作、狀態與結算；透過定位或直接扣血完成的 fixture 不等同自然遊玩。測試數量與最新結果由 [VERIFICATION.md](VERIFICATION.md) 記錄；首次玩家難度、完整遊玩時間及實體手機手感仍需實測。
